# Sobre as Versões do Projeto

Este projeto possui duas versões principais:

## Sem Modulos

- **Descrição:** Versão crua do projeto.
- **Características:** Não possui módulos de classe, mantendo a estrutura mais simples e direta.

## Modulos

- **Descrição:** Versão alternativa do projeto.
- **Características:** Inclui módulos das classes e fragmentos para as faces, aumentando a complexidade de alguns objetos e proporcionando maior modularidade ao código para tratamento de colisão.


## Iniciar
- rodar o comandos: 
- `pip install -r 'requirements.txt'`
- `python main.py`

## Controles:
- **WASD** - Movimento e rotação
- **C** - Alternar modo de câmera
- **V** - Debug de colisão
- **.** - Abrir/fechar portão
- **F** - Interagir com objetos
- **ESC** - Sair
